# Dossier de conception (SAE3.ESE.01-02 AssistDomo)

- `Dossier_conception_AssistDomo_SEGUIER.pdf` : le dossier à rendre (un seul PDF).
- `generer_dossier.py` : régénère le PDF (`python3 docs/dossier_conception/generer_dossier.py`, depuis la racine du dépôt ; nécessite pypdf, reportlab, node + playwright).
- `captures/` : captures d'écran Home Assistant (PNG/JPG), insérées dans l'ordre alphabétique. La légende vient du nom du fichier : `1_tableau_de_bord.png` donne « Capture 1 : tableau de bord ».
- `home_assistant/` : YAML Home Assistant (tableau de bord, automatisations, configuration) repris en annexe B.

Le schéma structurel est pris dans `mSeguier/docs/mSeguier_schema.pdf` et le code dans `GouGouGaGAH_Application/`.
